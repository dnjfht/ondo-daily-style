[Codex에 붙여 넣을 요청 — 골격 결과에 판단 근거 퍼센트 + 촬영 가이드 표시]

골격진단 모듈을 v3.2로 올렸어. public/skeleton/skeleton.js, public/skeleton/personas.json, ondo_skeleton_api 폴더는 이미 새 버전으로 바뀌어 있어.
이 파일들의 계산 코드는 수정하지 말고, 화면(UI)만 아래처럼 바꿔 줘.

1) 결과 화면에 "판단 근거" 카드 추가
   diagnose() 결과에 result.percent 가 새로 생겼어. 구조:
   result.percent = {
     stage1: { question:"웨이브인가?", weights:{photo:50, survey:50},
               photo: 0~100, photoRange: ±%p 또는 null, photoUsed: true/false, photoSide: "웨이브 쪽"/"웨이브 아님 쪽"/"중립"/"사진 없음",
               survey: 0~100 또는 null, surveySide: ..., total: 0~100, cut: 55, result: "웨이브"/"웨이브 아님"/"경계(웨이브 아님 쪽)"/"보류(...)" },
     stage2: null 또는 { question:"스트레이트인가, 내추럴인가?", weights:{photo:0, survey:100}, photoNote:"...",
                        straight: 0~100, natural: 0~100, cut: 55, result: "스트레이트"/"내추럴"/"보류(중간)" },
     final: 0~100 또는 null, finalLabel: "웨이브 85%" / "판정 보류"
   }

   화면 구성 (위에서 아래로):
   ■ 최종: finalLabel 크게 + 기존 신뢰도(높음/보통/낮음)
   ■ 1단계 · 웨이브인가?  (사진 50% + 설문 50% 반영)
     - 사진  [막대] {photo}%  {photoSide}   ← photoRange가 있으면 "±{photoRange}%p" 작게 표시
                                               photoUsed가 false면 막대 대신 "사진 없음 (50% 중립으로 계산)"
     - 설문  [막대] {survey}%  {surveySide}
     - 종합  [막대] {total}%   → {result}   (막대에 55% 기준선 표시)
   ■ 2단계 · 스트레이트인가, 내추럴인가?  (설문 100% 반영) — stage2가 null이면 이 칸은 숨김
     - 스트레이트 {straight}% | 내추럴 {natural}%  (가로 막대 하나를 두 색으로 나눔, 45~55% 구간은 '보류' 표시)
     - 작은 글씨: {photoNote}
   ■ 안내 문구(작게): "퍼센트는 사진·설문 점수를 0~100으로 바꾼 값이에요. 최종 %는 판정에 쓰인 단계 중 가장 약한 단계의 값입니다."

   막대 색: 웨이브 쪽 = 분홍, 웨이브 아님 쪽 = 회색, 스트레이트 = 파랑, 내추럴 = 초록 정도로 구분. 텍스트로도 값을 보여 줘서 색만으로 구분하지 않게.

2) 사진 업로드 칸의 촬영 가이드 (업로드 버튼 위에 항상 표시)
   "정확하게 분석하려면"
   · 머리 위부터 발끝까지 전신이 나오게, 사람이 사진 세로의 80% 이상 차도록
   · 카메라는 허리 높이에서 수평으로, 정면을 보고 똑바로 서기
   · 몸에 붙는 옷 (오버핏·롱코트·치마 부풀림 X), 머리카락이 어깨선을 가리지 않게
   · 팔은 몸에서 주먹 하나만큼 떼고 자연스럽게 내리기
   · 단색 배경, 밝은 곳, 원본 화질 그대로 (캡처·메신저로 줄인 사진 X)

3) API 응답의 촬영 피드백 표시
   - 성공 응답 persona.quality.tips (문자열 배열)가 비어 있지 않으면, 사진 미리보기 아래에 노란 안내 박스로
     "이렇게 다시 찍으면 더 정확해요" + tips 목록을 보여 줘. (분석은 그대로 진행)
   - 실패 error가 "not_full_body"이면 message("발끝이 보이지 않아요 ...")를 보여 주고 설문만으로 진행.
   - 사진 분석은 6번 재서 평균을 내느라 몇 초 걸릴 수 있으니, 요청 중에는 "사진 분석 중… (약 5초)" 로딩 표시.

4) 지켜야 할 것 (기존과 동일)
   - 사진은 http://127.0.0.1:8000 로컬 API로만 일회성 전송, 원본은 저장하지 않기 (body_photo_path 저장 금지)
   - 퍼스널컬러 셀카는 전송하지 않기
   - skeleton.js / personas.json / ondo_skeleton_api 안의 계산 코드는 수정하지 않기
   - 기존 요청대로 사진 요약은 result.photoSupport만, photoAgainst는 숨김
