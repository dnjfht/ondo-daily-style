public/skeleton/skeleton.js를 새 버전으로 교체했어 (판정 계산은 동일, 결과에 표시용 필드만 추가됨).
diagnose() 결과에 아래 필드가 새로 생겼어:
- result.photoSupport : 결과 유형을 뒷받침하는 사진 특징 (문자열 배열)
- result.photoAgainst : 결과와 반대되는 사진 특징 (예: "허리 굴곡이 적은 일자형 (내추럴 쪽 특징)")
- result.reasons : 이제 뒷받침하는 사진 근거 + 설문 근거만 들어 있음

골격 결과 화면을 이렇게 바꿔줘:
1) "사진 분석 요약" 박스와 근거 목록에 같은 사진 문장이 두 번 나오지 않게 해줘.
2) 결과 카드의 근거 목록은 result.reasons만 보여줘.
3) result.photoAgainst가 있으면 그 아래에 작은 회색 글씨로
   "참고: 사진에서 다른 유형의 특징도 보였어요 — (photoAgainst 목록)"을 보여줘. 신뢰도가 낮은 이유를 설명하는 용도야.
4) 사진을 올린 직후 미리보기(결과 보기 전)에는 지금처럼 persona.photoReasons 전체를 "사진에서 보인 특징"으로 보여줘도 돼.
skeleton.js의 계산 로직은 수정하지 마.
